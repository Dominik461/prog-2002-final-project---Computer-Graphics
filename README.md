# Information

This was my final project in the computer graphics class, were the task was to develop a 3D Tetris like game inspired by the classic BlockOut.

It was fully developed with C++ and OpenGL.

## Folder structure

```./exam/game``` - contains the game logic and setting the object data to the buffers

```./exam/renderer``` - contains the render calls and shaders

```./exam/resources/textures``` - contains texture files 

```./framework``` - contains a self developed OpenGL framework for rendering

```./external``` - contains the external libraries glad, glfw, glm and stb used in the framework

## Controls

```arrow keys``` - moving the block	

```X``` - move block by one section

```space``` - move block to the end or collision with other block

```T``` - toggle textures

```Q``` - Pitch clockwise

```A``` - Pitch counter clockwise

```W``` - Yaw clockwise

```S``` - Yaw counter clockwise

```E``` - Roll clockwise

```D``` - Roll counter clockwise
